Door-Unlocking Mechanism

Embedded systems · Arduino keypad entry
Prototype

Arduino keypad entry for shared spaces: replaces a copyable key with a credential that can be granted, changed or revoked without touching the hardware.

  • Non-blocking firmware state machine: entry, verification, unlock window, lockout, with timeouts so it always returns to a known state
  • Lockout after repeated wrong entries; buzzer and LED feedback designed to read without a display
  • Lock actuator driven through a transistor rather than a GPIO pin, protecting the controller
  • Sole designer and builder across the circuit, firmware and mechanical integration

64-bit CPU Project

Computer architecture · Independent study
Independent study

Designed a 64-bit processor end to end, from instruction set to a pipelined implementation, then wrote the programs that exercise it.

  • Specified the ISA first: opcodes, formats, addressing modes and the register file
  • Single-cycle baseline as ground truth, then added stages, forwarding and hazard handling
  • Control unit derived from the datapath rather than designed separately from it
  • Simulation-led verification of each instruction's effect on registers and memory
